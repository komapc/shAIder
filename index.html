shAIder: an AI shader generator, from text to GLSL

Describe a material in plain words, for example “molten lava with glowing cracks” or “a blue hologram with moving scanlines”, and shAIder writes the vertex and fragment shaders for you. The result is a WebGL shader from a prompt, compiled and rendered live on a sphere, cube, torus or plane right in your browser.

How it works

  • Write one prompt for the material and, if you like, a second one for the scene layout.
  • The AI returns GLSL code. If it does not compile, the error goes back to the model and it fixes the shader on its own.
  • Sliders appear for the shader’s uniforms, so you can tune colours, speed and scale without touching code.
  • Edit the GLSL by hand in the built-in editor, or ask for a refinement of the current result.

Export to Three.js

When you are happy with the look, export it as a standalone HTML page that runs the shader with Three.js. Open it locally, or copy the GLSL into your own Three.js, WebGL or game project.

shAIder is free and needs no account. The source code is on GitHub.
